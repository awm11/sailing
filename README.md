# Close Hauled

A top-down sailing game in a single HTML file. Steer with the rudder, trim the sail, balance the boat and read the wind from the water.

**Play:** https://awm11.github.io/sailing/

## Modes
- **Open water**: free sailing in wind that shifts and changes strength, with seven drills that teach the points of sail.
- **Race course**: cross the start line, round three marks (keep them on your left), avoid rocks, an island and moored boats, then finish upwind.

## Controls
| Key | Action |
| --- | --- |
| ← → (A D) | Rudder: steer left / right |
| ↑ ↓ (W S) | Pull the sail in / let it out |
| Q E, or two-finger sideways swipe | Lean your weight left / right to balance the boat |
| I | Reverse the swipe direction |
| Space (hold) | Right the boat after a capsize |
| T | Auto-trim the sail |
| H / P / R / M | Tips / pause / restart / menu |

## Run locally
Open `index.html` in a browser. There is no build step.
